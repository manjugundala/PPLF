# Getting help

| You want to… | Go to |
|---|---|
| Learn how to install or use PPLF | [Documentation](https://manjugundala.github.io/PPLF/) · [Prerequisites](docs/prerequisites.md) · [Getting started](docs/getting-started.md) · [FAQ](docs/faq.md) |
| Fix an error you are seeing | [Troubleshooting](docs/troubleshooting.md) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/manjugundala/PPLF/discussions) |
| Report a bug | [Open an issue](https://github.com/manjugundala/PPLF/issues/new/choose) with the bug template |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Do not open a public issue. |

PPLF is a community project maintained in spare time. There is no service-level agreement; issues are triaged weekly.
When you ask for help, include the PPLF version (solution version in Dataverse), the log target and the exact error text.

Power Platform product issues (not PPLF) go to [Microsoft support](https://admin.powerplatform.microsoft.com/support).
