# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussion about the work.
Harassment of any kind is not accepted.

Report problems privately to the maintainers through GitHub's **Security → Report a vulnerability** form (choose "conduct" in the title) or by contacting a maintainer listed in `.github/CODEOWNERS`. Reports are handled confidentially.
